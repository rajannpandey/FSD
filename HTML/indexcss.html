CSS Styling

This is a simple paragraph to demonstrate inline CSS styling.

Inline CSS allows you to apply styles directly to HTML elements using the style attribute.

You can change the text color, font size, and other styles using inline CSS.

However, it's generally recommended to use external or internal CSS for better maintainability and separation of concerns.

Inline CSS can be useful for quick styling or testing, but it's not ideal for larger projects.

Remember to use inline CSS sparingly and consider using external stylesheets for a cleaner and more organized codebase.
